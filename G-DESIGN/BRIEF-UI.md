# BRIEF-UI — dry-run (NEAR, track AI Security & Defense)

## Concept
Pare-feu de simulation pour wallets d'agents : chaque transaction est
simulée et notée (risque) avant exécution. Approve / block éclairé.

## Écrans clés
1. Simulation de transaction (avant/après, diffs d'état).
2. Rapport de risque (score, facteurs, explications).
3. File d'approbation (approve / block en un clic).
4. Historique + alertes (patterns d'attaque détectés).
