# G-DESIGN — design history

This folder is **build history, not product**. It holds the design briefs, the
hand-off notes exchanged while the interface was being built, and the design
boards (as HTML/JS, so they stay readable in a browser). Nothing here is
required to run, build or judge Dry Run.

The reference documents are the top-level `README.md`, `docs/SPEC.md` and
`docs/SPEC_V1_MAX.md`.

Two things to know if you read these notes:

- they are **dated snapshots**. Some of them describe the trap corpus with
  **six** traps: the seventh (`two-face`, caught by the differential
  simulation, rule R12) was designed later. The corpus that ships today has
  **seven**, and `make attack` plays all seven;
- they are written in French, as the working language of the build. The
  product itself — README, CLI, web page, MCP answers — is in English.

Everything in the repository is versioned on purpose: the history of the
project is part of the submission (see section 10 bis of the README).
